schema help · parameter reference ▶
body: width, height, depth, corner (0–1), bevel (0–1), cornerSegments (rounding fidelity, default 16), bevelSegments (depth rounding fidelity, default 16), flatShading / smoothShading (faceted vs smooth lighting; material.flatShading wins if both set), material: { color, roughness (0–1), metalness (0–1), opacity (0–1, default 1) }
knobs[]: label, labelColor, labelSize, x, y, radius, height, value (0–1), topRounding (0–1), segments, smoothShading (default true; false uses faceted lighting), skirtFactor (0–1), skirtRounding (0–1), markColor, markLength (∝ radius), markWidth (∝ radius), material: { color, roughness, metalness, opacity }
buttons[]: label, labelColor, labelSize, labelPosition ("on"/"above"/"below"), x, y, width, length, height, travel (press depth along z, default 0.65·height), roundedness (0–1), material: { color, roughness, metalness, opacity }
  labelPosition "on" (default) shows a flat icon on the cap — play/stop/rec/etc. auto-map to monochrome symbols
sliders[]: label, labelColor, labelSize, x, y, length, orientation (deg), value (0–1), capWidth, capLength, capHeight, capRoundedness (0–1), material: { color, roughness, metalness, opacity }
labels[]: text, x, y, fontsize, font, fontweight, align ("left"/"center"/"right"), material: { color, roughness, metalness, opacity }
lcd: width, height, x, y, bezel, bezelColor, roundedness (0–1), text, textColor, backgroundColor, material: { color (bezel fallback), roughness (0–1), metalness (0–1), opacity }
surface: z (height at which the surface plane is drawn, default 0; physics always uses z=0 as its boundary), material: { color, roughness, metalness, opacity }, texture: { pattern: grid|dots|checker|stripes, size (world units per tile, default 2), width (line/dot/stripe thickness in world units, default 0.06), offset: [x,y], color (grid lines), background (cells, defaults to the material color), enabled }
skybox: enabled (default true), color (single flat color, default "#14161c"), circleColor (default "#ffffff"), circles (count, default 5), circleSize (soft falloff radius in px, default 16), circleSpread (scatter factor, default 1; 0 stacks all circles at one point), randSeed (layout seed, default 1337), radius (default 40), envIntensity (scales the skylight on PBR materials, default 1 — try 2–4 for a dark sky) — the texture also feeds scene.environment, so PBR materials reflect the sky
spotlight: x, y, z, color, intensity, shadowRadius (blur/softness, default 8), shadowBias, shadowNormalBias, shadowMapSize
fillLight: color, intensity (fixed-position secondary light)
fillLight2: color, intensity (second fixed-position fill light)
ambientLight: color, intensity (diffuse baseline ambient light)

render: pixelRatio (0.5–2), shadows, shadowMapSize, softboxShadowCount, detailShadows, continuous, showFps
physics: enabled, dropHeight, tilt {x,y,z} (drop tilt in radians), restitution (bounciness 0–1), friction, gravity (vector {x,y,z} in m/s², or a scalar for the y component)
constants: { name: value, ... } — any string value anywhere in the config that exactly matches a name is replaced with its value (any JSON type, any depth)

In knobs[]/buttons[]/sliders[]/labels[]: entry 0 should set every field it needs. Later entries inherit any omitted field from the entry before them (material sub-fields merge independently). Omitted x/y continue the sequence: x[n] = 2·x[n-1] − x[n-2].

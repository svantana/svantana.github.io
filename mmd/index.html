schema help · parameter reference ▶
body: width, height, depth, roundedness (0–0.5), segments (rounding fidelity, default 8), color, roughness (0–1), metalness (0–1)
knobs[]: label, labelColor, labelSize, x, y, radius, height, color, roughness, metalness, value (0–1), roundedness (0–1), segments
buttons[]: label, labelColor, labelSize, labelPosition ("on"/"above"/"below"), x, y, width, length, height, travel, color, roughness, metalness, pressed
  labelPosition "on" (default) shows a flat icon on the cap — play/stop/rec/etc. auto-map to monochrome symbols
sliders[]: label, labelColor, labelSize, x, y, length, orientation (deg), value (0–1), color, roughness, metalness, capWidth, capLength, capHeight
labels[]: text, x, y, fontsize, font, fontweight, color
lcd: width, height, x, y, text, textColor, backgroundColor
surface: color, grid: { size, color, linewidth }
light: x, y, z, color, intensity, shadowRadius (blur/softness, default 8), shadowBias, shadowNormalBias, shadowMapSize
fillLight: color, intensity (fixed-position secondary light)
ambientLight: color, intensity (diffuse baseline ambient light)

render: pixelRatio (0.5–2), shadows, shadowMapSize, softboxShadowCount, detailShadows, continuous, showFps

In knobs[]/buttons[]/sliders[]/labels[]: entry 0 should set every field it needs. Later entries inherit any omitted field from the entry before them. Omitted x/y continue the sequence: x[n] = 2·x[n-1] − x[n-2].

schema help · parameter reference ▶
body: width, height, depth, roundedness (0–0.5), segments (rounding fidelity, default 8), material: { color, roughness (0–1), metalness (0–1) }
knobs[]: label, labelColor, labelSize, x, y, radius, height, value (0–1), topRounding (0–1), segments, skirtFactor (0–1), skirtRounding (0–1), markColor, markLength (∝ radius), markWidth (∝ radius), material: { color, roughness, metalness }
buttons[]: label, labelColor, labelSize, labelPosition ("on"/"above"/"below"), x, y, width, length, height, travel, roundedness (0–1), pressed, material: { color, roughness, metalness }
  labelPosition "on" (default) shows a flat icon on the cap — play/stop/rec/etc. auto-map to monochrome symbols
sliders[]: label, labelColor, labelSize, x, y, length, orientation (deg), value (0–1), capWidth, capLength, capHeight, capRoundedness (0–1), material: { color, roughness, metalness }
labels[]: text, x, y, fontsize, font, fontweight, align ("left"/"center"/"right"), material: { color, roughness, metalness }
lcd: width, height, x, y, text, textColor, backgroundColor, material: { color (bezel), roughness (0–1), metalness (0–1) }
surface: material: { color, roughness, metalness }, grid: { size, color, linewidth }
spotlight: x, y, z, color, intensity, shadowRadius (blur/softness, default 8), shadowBias, shadowNormalBias, shadowMapSize
fillLight: color, intensity (fixed-position secondary light)
fillLight2: color, intensity (second fixed-position fill light)
ambientLight: color, intensity (diffuse baseline ambient light)

render: pixelRatio (0.5–2), shadows, shadowMapSize, softboxShadowCount, detailShadows, continuous, showFps, wireframe
physics: enabled, dropHeight, tilt {x,y,z} (drop tilt in radians), restitution (bounciness 0–1), friction

In knobs[]/buttons[]/sliders[]/labels[]: entry 0 should set every field it needs. Later entries inherit any omitted field from the entry before them (material sub-fields merge independently). Omitted x/y continue the sequence: x[n] = 2·x[n-1] − x[n-2].
